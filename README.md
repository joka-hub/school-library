# 📚 المكتبة الرقمية لمدرسة قومية العجوزة — School Digital Library

مشروع متكامل: **Frontend + Backend + Database + Authentication + File Upload + Admin Dashboard**

- Backend: Node.js + Express
- Database: MongoDB (نستخدم MongoDB Atlas المجاني — بيانات دائمة حقيقية)
- تخزين الملفات (صور/PDF/فيديو): Cloudinary (مجاني، دائم، لا يُمسح عند إعادة النشر)
- تسجيل الدخول: JWT + تشفير كلمة المرور (bcrypt)
- الواجهة: HTML/CSS/JavaScript عربي RTL بدون أي Framework إضافي (يعمل بسرعة على أي جهاز)

لا يحتاج المشروع أي اشتراك مدفوع مع الاستخدام العادي لمكتبة مدرسة واحدة.

---

## الخطوة 1: إنشاء قاعدة البيانات (MongoDB Atlas - مجاني للأبد)

1. اذهبي إلى https://www.mongodb.com/cloud/atlas/register وأنشئي حساب مجاني.
2. أنشئي **Cluster** جديد واختاري الخطة المجانية **M0 Free**.
3. من **Database Access** أنشئي مستخدم قاعدة بيانات (اسم مستخدم + كلمة مرور) واحتفظي بهم.
4. من **Network Access** اضغطي **Add IP Address** ثم اختاري **Allow Access from Anywhere** (0.0.0.0/0) — ضروري عشان Render يقدر يتصل.
5. من **Connect → Drivers** انسخي رابط الاتصال (Connection String)، شكله يكون تقريبًا:
   ```
   mongodb+srv://username:password@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
   ```
6. غيّري `username` و`password` بالبيانات اللي عملتيها، وأضيفي اسم قاعدة البيانات بعد `.net/` كده:
   ```
   mongodb+srv://username:password@cluster0.xxxxx.mongodb.net/school_library?retryWrites=true&w=majority
   ```
   ده هو الـ `MONGO_URI` اللي هتستخدميه.

---

## الخطوة 2: إنشاء تخزين الملفات (Cloudinary - مجاني)

1. اذهبي إلى https://cloudinary.com/users/register/free وأنشئي حساب مجاني.
2. من الـ Dashboard هتلاقي مباشرة:
   - `Cloud Name`
   - `API Key`
   - `API Secret`
3. احتفظي بيهم، هتحتاجيهم في الخطوة الجاية.

الخطة المجانية بتدّيكي حوالي 25GB تخزين و25GB نقل بيانات شهريًا — أكتر من كافي لمكتبة مدرسة.

---

## الخطوة 3: تجربة المشروع على جهازك (اختياري لكن يُنصح به)

1. ثبّتي [Node.js](https://nodejs.org) (نسخة 18 أو أحدث).
2. افتحي مجلد المشروع في الترمينال ونفّذي:
   ```
   npm install
   ```
3. انسخي ملف `.env.example` وسمّيه `.env`، واملئي فيه القيم الحقيقية اللي جمعتيها فوق (`MONGO_URI`, `CLOUDINARY_*`, وغيّري `JWT_SECRET` لأي نص عشوائي طويل).
4. شغّلي أمر إنشاء أول حساب أدمن:
   ```
   npm run seed:admin
   ```
   هيطبعلك اسم المستخدم وكلمة المرور اللي حددتيها في `.env` (`ADMIN_USERNAME` و`ADMIN_PASSWORD`).
5. شغّلي السيرفر:
   ```
   npm start
   ```
6. افتحي المتصفح على `http://localhost:5000` — المفروض الموقع يشتغل، وتقدري تدخلي لوحة الإدارة من `http://localhost:5000/admin/login.html`.

---

## الخطوة 4: النشر المجاني على Render (الموقع بيبقى عام ودائم)

1. ارفعي مجلد المشروع على GitHub (أنشئي Repository جديد وارفعي كل الملفات — **بدون** ملف `.env`، هو أصلاً متجاهل تلقائيًا).
2. اذهبي إلى https://render.com وسجّلي حساب مجاني (تقدري تسجلي دخول بحساب GitHub مباشرة).
3. من لوحة Render اضغطي **New → Web Service** واختاري الـ Repository بتاعك.
4. الإعدادات:
   - **Name**: أي اسم تحبيه، مثلاً `school-digital-library`
   - **Region**: اختاري الأقرب جغرافيًا
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: `Free`
5. في قسم **Environment Variables** أضيفي المتغيرات دي واحد واحد (نفس أسماء `.env`):
   - `MONGO_URI`
   - `CLOUDINARY_CLOUD_NAME`
   - `CLOUDINARY_API_KEY`
   - `CLOUDINARY_API_SECRET`
   - `JWT_SECRET` (نص عشوائي طويل من عندك)
   - `NODE_ENV` = `production`
6. اضغطي **Create Web Service** وانتظري لحد ما يخلص النشر (حوالي 2-3 دقائق).
7. هتحصلي على رابط دائم شكله:
   ```
   https://school-digital-library.onrender.com
   ```
   ده الرابط العام لموقعك، أي حد يقدر يفتحه من غير تسجيل دخول في أي حاجة.

### إنشاء أول حساب أدمن بعد النشر

الطريقة الأسهل: من Render افتحي **Shell** الخاص بالـ Web Service بتاعك (تبويب Shell في صفحة السيرفس) ونفّذي:
```
npm run seed:admin
```
هيستخدم القيم اللي حطيتيها في Environment Variables (`ADMIN_USERNAME`, `ADMIN_PASSWORD`) لو أضفتيهم، أو القيم الافتراضية `admin` / `ChangeMe123!` لو مأضفتهمش — **مهم جدًا تغيّري كلمة المرور فورًا بعد أول دخول من صفحة الإعدادات**.

### ملاحظة عن خطة Render المجانية
الخطة المجانية بتنام السيرفر لو مفيش زيارات لمدة 15 دقيقة، وأول زيارة بعدها بتاخد حوالي 30-50 ثانية عشان يصحى. ده طبيعي وميأثرش على البيانات أو الملفات المرفوعة، بس لو عايزة السيرفر يفضل صاحي طول الوقت من غير أي تأخير، ممكن تترقّي لخطة Starter المدفوعة الرخيصة لاحقًا.

## هيكل المشروع

```
school-digital-library/
├── server.js               # نقطة تشغيل السيرفر
├── config/                 # اتصال قاعدة البيانات وCloudinary
├── models/                 # نماذج قاعدة البيانات (Book, Magazine, Resource, News, Photo, Album...)
├── controllers/             # منطق العمليات (CRUD, بحث, مصادقة, إحصاءات)
├── middleware/              # حماية المسارات، رفع الملفات، معالجة الأخطاء
├── routes/                  # مسارات الـ API
├── scripts/seedAdmin.js     # إنشاء أول حساب أدمن
└── public/                  # الواجهة الأمامية (HTML/CSS/JS)
    ├── index.html            # الرئيسية
    ├── section.html          # عرض قسم (كتب/مجلات/موارد/أخبار) بفلاتر وبحث
    ├── item.html             # تفاصيل + قراءة الملف
    ├── photos.html / album.html
    ├── search.html
    └── admin/                # لوحة الإدارة (تسجيل دخول + Dashboard)
```

## أقسام الموقع وربطها بالموارد

عشان نبني نظام حقيقي ومركزي بدل تكرار نفس الكود 10 مرات، الأقسام دي بتتغذى من نموذج **الموارد التعليمية** مع فلتر "الركن":
- **ركن المعلم** ← موارد بركن = "ركن المعلم"
- **ركن الطالب** ← موارد بركن = "ركن الطالب"
- **الذكاء الاصطناعي والتكنولوجيا** ← موارد بركن = "الذكاء الاصطناعي والتكنولوجيا"
- **المعارض الرقمية** ← موارد بركن = "المعارض الرقمية"
- **المكتبة الافتراضية** ← نفس قسم الكتب الرقمية

كده أي مورد تضيفيه من لوحة الإدارة وتحددي له "الركن" المناسب، هيظهر تلقائيًا في الصفحة الصحيحة.

## الأمان

- كل عمليات الإضافة/التعديل/الحذف/رفع الملفات محمية بـ Middleware في السيرفر (`protect`) بيتحقق من توكن JWT صادر بعد تسجيل دخول صحيح — مش JavaScript في المتصفح بس، فمينفعش حد يتجاوزها بتعديل الكود من المتصفح.
- كلمات المرور مشفّرة بـ bcrypt، مفيش أي كلمة مرور محفوظة كنص عادي.
- في حساب "مدير رئيسي" (Owner) واحد بس يقدر يضيف حسابات إدارية جديدة، والباقي "محررين" يقدروا يديروا المحتوى بس.

## التوسع لاحقًا

المشروع مبني بطريقة قابلة للتوسع بسهولة:
- إضافة حقل أو نوع محتوى جديد = إضافة سطر في `models/` و`CONTENT_TYPES` بملف `admin.js`.
- ممكن إضافة صفحة "ركن المعلم" أو "ركن الطالب" بتصميم مختلف مستقل لاحقًا لو احتجتي.
- ممكن ربط دومين مخصص للمدرسة (زي `library.your-school.edu.eg`) من إعدادات Render مجانًا بعد شراء الدومين.
